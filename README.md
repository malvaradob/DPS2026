# 🚀 React 24 + TypeScript 6.0 + Vite 8

# 📚 Laboratorio de React + TypeScript

Este repositorio contiene una colección de **9 ejemplos prácticos** desarrollados con **React 19**, **TypeScript 5.9** y **Vite 8**, diseñados para aprender TypeScript desde un enfoque completamente práctico e integrado con React.

Cada ejemplo introduce nuevos conceptos del lenguaje y muestra cómo utilizarlos dentro de componentes React modernos.

# 💻 Instalación

Clonar el repositorio

```bash
git clone https://github.com/malvaradob/DPS2026.git
```

Ingresar al proyecto

```bash
cd clase02
```

Instalar dependencias

```bash
npm install
```

Ejecutar

```bash
npm run dev
```

Abrir

```text
http://localhost:5173
```

# 🚀 Crear el proyecto desde cero

Crear proyecto

```bash
npm create vite@latest
```

Seleccionar

```text
Project Name:
react-typescript-ejemplos

Framework:
React

Variant:
TypeScript
```

Entrar al proyecto

```bash
cd react-typescript-ejemplos
```

Instalar dependencias

```bash
npm install
```

Ejecutar

```bash
npm run dev
```
