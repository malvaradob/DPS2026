# 🚀 React 24 + TypeScript 6.0 + Vite 8

# 📚 Ejemplo de retroalimentación

Una librería desea desarrollar una pequeña aplicación utilizando React + TypeScript para aprender los conceptos fundamentales de React.
La aplicación debe permitir:
* Mostrar un listado de libros. 
* Marcar o desmarcar libros como favoritos 
* Mostrar la cantidad de libros favoritos
* Seleccionar un libro para visualizar su información. 

---

# 📖 Objetivos de implementación

Aplicar los siguiente conceptos:
* 1.	Props
* 2.	State
* 3.	Renderizado
* 4.	Manejo de eventos
* 5.	Hooks principales

---

# 💻 Instalación

Clonar el repositorio

```bash
git clone https://github.com/malvaradob/DPS2026.git
```

Ingresar al proyecto

```bash
cd clase03-feedback
```

Instalar dependencias

```bash
npm install
```

Ejecutar

```bash
npm run dev
```

Abrir

```text
http://localhost:5173
```

---

# 🚀 Crear el proyecto desde cero

Crear proyecto

```bash
npm create vite@latest
```

Seleccionar

```text
Project Name:
biblioteca

Framework:
React

Variant:
TypeScript
```

Entrar al proyecto

```bash
cd biblioteca
```

Instalar dependencias

```bash
npm install
```

Ejecutar

```bash
npm run dev
```
